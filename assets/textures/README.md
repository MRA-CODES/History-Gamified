# textures

Put separate texture image files here: the PNG, JPG, or EXR images that
wrap onto 3D models (albedo/color, normal, roughness, and similar maps).

Expected files:
- .png, .jpg, .webp, or .exr image files
- name each texture to match the model it belongs to, for example
  church_exterior_albedo.png

Textures that a model pack ships inside its own GLB are already part of
the model and stay inside it. Do not extract them.
