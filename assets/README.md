# assets

This folder holds all the raw files your game uses, such as 3D models
(GLB), textures, and materials.

Subfolders keep each type of asset in its own place:

- environment/  - buildings, city scenery, props, imported and generated assets
- characters/   - character models
- animations/   - animation files
- textures/     - image files used on model surfaces
- materials/    - material files that define how surfaces look

Do not put scenes, scripts, or UI files here. They live in their own
top-level folders. See ASSET_PLACEMENT.md in the project root for the
full guide.
