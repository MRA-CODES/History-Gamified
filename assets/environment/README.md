# environment

Environment assets are the 3D world around the player: buildings, city
scenery, and props.

- buildings/  - whole buildings (for example the Victorian church exterior)
- city/       - city scenery (streets, plazas, background districts)
- props/      - smaller objects that can be placed (benches, signs, trees)
- imported/   - raw assets downloaded or received from outside, unmodified
- generated/  - assets created or exported by Summer Engine tools

See ASSET_PLACEMENT.md in the project root for exactly where each file
goes.
