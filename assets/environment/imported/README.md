# imported

Put raw environment assets that came from outside the project here,
exactly as received and unmodified: downloaded GLB/GLTF packs, reference
files, and source assets from Summer Curated Assets or other sources.

Keep imported files separate from generated files so you always know
which assets are original sources and which were produced inside this
project.

Do not hand-edit files in this folder. When an imported model is ready
to be used, copy it to its final home in buildings/, city/, or props/.
