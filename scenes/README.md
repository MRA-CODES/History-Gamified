# scenes

Put Godot scene files here. A scene is a .tscn file that arranges nodes
into something playable or reusable, such as the main game scene, a
character scene, or a UI scene.

Expected files:
- .tscn scene files

Scripts attached to scenes live in res://scripts/, not here.

This phase is organization only - no scene files exist yet. When scene
work starts, every new scene goes in this folder.
